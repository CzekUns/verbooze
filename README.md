# Verbooze

Portale indipendente di videogiochi. Prima versione: un'unica landing dedicata a GAM — Grand Asse Mediano: Melito.

## Cloudflare Pages
Collegare la repository privata a Cloudflare Pages, branch `main`, framework None, nessun comando di build, cartella di output `/` (radice della repository).

La landing statica usa un artwork GAM locale e un solo collegamento al gioco attualmente ospitato su GitHub Pages. Quando il gioco sarà migrato e ripulito, sostituire l'href in `index.html` con il percorso definitivo (ad esempio `/grandassemediano/`). Nessun tracking, pubblicità o link social ancora attivi. La migrazione del gioco non fa parte di questo intervento.
